# 카페 온기 랜딩페이지

따뜻한 감성의 카페를 위한 심플한 원페이지 랜딩페이지입니다.
HTML / CSS / JavaScript만으로 제작되어 별도의 빌드 과정 없이 바로 사용할 수 있습니다.

## 미리보기 구성

- **Header / Nav** — 상단 고정 내비게이션, 모바일 햄버거 메뉴 지원
- **Hero** — 카페 소개 문구와 메뉴 바로가기 버튼
- **Menu** — 시그니처 메뉴 4종 카드 그리드 (이름 / 설명 / 가격)
- **About** — 카페 소개와 운영 통계
- **Location** — 주소, 영업시간, 연락처
- **Footer** — 카피라이트

## 파일 구조

```
landing/
├── index.html   # 페이지 마크업
├── style.css    # 스타일 (반응형 포함)
├── script.js    # 모바일 메뉴 토글 스크립트
└── README.md
```

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

```bash
# 예: VS Code Live Server, 혹은 아래처럼 간단히 정적 서버 실행
npx serve .
```

## 커스터마이징

- `style.css` 상단 `:root` 변수에서 색상 테마를 한 번에 변경할 수 있습니다.
- `index.html`의 메뉴/소개/연락처 텍스트를 실제 매장 정보로 교체하세요.
- 720px 이하 화면에서는 내비게이션이 햄버거 메뉴로 전환됩니다.
